## 3. 🔴 言ってはいけないこと

| ✕ | ○ | なぜ |
|---|---|---|
| **寄付します** | **お渡しします／充てられます** | 購入型クラファンでは「寄付」と約束できない |
| **投資する／未来へ投資** | **育てる／未来を育てる** | 購入型と矛盾する禁止表現 |
| **会場名（ビル名・店名）** | **渋谷の室内フロア** | 会場の解禁日がまだ決まっていない |
| **支援先の団体名** | **然るべき団体** | 開催後に報告する方針 |
| **シャンパンコール** | **限定メッセージ動画** | ホストクラブの用語 |
| **見送り／相席（軽い口調で）** | **終演／お席は主催者が指定します** | 夜の業界の言葉に聞こえる |
| **「いくら入れてくれたら◯◯する」** | **ページに書いてある条件だけを説明する** | **金額で関係性が変わる誘導は絶対にしない** |
| **世界で一番／絶対** | **私たちはこう思っています** | 根拠のない断定 |

### とくに気をつける1点

**CAMPFIRE の担当者から「ホスト × チャリティー」で炎上する可能性を指摘されています。**

配信中、**支援額と個人的な関係を結びつける言い方をしない。**
「〇〇さんありがとう！」と名前を呼ぶのは構いませんが、
**「たくさん入れてくれた人」という扱いの差をつけない。**

これは配信が切り取られたときに、一番効く違いになります。
