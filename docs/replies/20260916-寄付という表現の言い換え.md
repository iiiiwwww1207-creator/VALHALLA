# 「寄付」を使わない書き方（CAMPFIRE 掲載ページ）

## 答え：**「寄付します」→「収益を◯◯の活動に充てます」**

言い換えの当てずっぽうではありません。**昼の本編ページ（同じアカウントで、すでに審査を通って公開中）が、この書き方をしています。**

> 本公演はチャリティーとして実施し、**開催までにかかった経費を除いた収益の全額を文化継承・教育支援の活動に充てること**を予定しています。使途は「教育・文化プログラムの実施」「AIリテラシー教育コンテンツの制作」「文化のデジタルアーカイブ化」「地域文化の記録と若い世代の育成」の4分野です。
> （東京大学・安田講堂プロジェクト／Q3「支援金は何に使われますか？」より）

> 本公演の収益については、**開催経費を除いた上で、今後の文化継承・教育支援活動、AIを活用した文化の記録・デジタルアーカイブなどへつなげていきます。**
> （同／「9. 資金の使い道」より）

**通った実例をそのままなぞるのが一番確実です。**

---

## なぜ「寄付」が引っかかるのか

CAMPFIRE の購入型クラウドファンディングは、法的には**売買**です。支援者はリターンを買っているのであって、寄付をしているわけではありません。集まったお金も、いったんは実行者の売上になります。

そこで「**集まった支援金を寄付します**」と書くと、

- 支援者から見て「自分が寄付をした」と読める（寄付金控除の誤認につながる）
- 寄付型クラウドファンディングという**別の枠**の体裁になってしまう

この2点が問題になります。

### ただし「寄付」という語が全面禁止なわけではありません

昼のページでも、次の2つの文脈では使われています。

- **過去の事実として**：「東大基金への寄付を通じ、……活動を支援してきました」
- **リターンのコース名として**：「来場を伴わない応援・寄付コース」

つまり止められているのは、**これから集める支援金を「寄付する」と約束する書き方**だけです。

---

## 書き換えの4つのルール

| | ルール | 例 |
|---|---|---|
| 1 | **動詞を替える** | 寄付します → **充てます／つなげていきます／活用します** |
| 2 | **主語を「収益」にする**（支援者を主語にしない） | あなたの支援が寄付になる → **本公演の収益を、……に充てます** |
| 3 | **断定しない** | 寄付します → **充てることを予定しています** |
| 4 | **抽象語を具体的な使途に置き換える** | 然るべき団体へ → **AIリテラシー教育コンテンツの制作など** |

ルール4には副産物があります。**使途を具体的に書けば、「寄付先の団体名」を書く必要がそもそも無くなります。**
前回ご指摘いただいた【1】（4か所が「然るべき団体」のまま）も、**この書き換えで同時に解消します。**

## あわせてご確認いただきたい2点

### 1. フライヤーには「寄付いたします」が印刷済みです

この文言はもともと**先方からのご指定**でした。CAMPFIRE の規約上ページ側だけ書き換えると、**紙とページで言い方が変わります。**
規約由来の変更なので問題にはなりにくいと考えますが、**先方には一言お通ししておいたほうが安全**です。

### 2. 「決済手数料」は経費から外すことを推奨します

本プロジェクトは CAMPFIRE for Social Good 枠で、**オーナー側の手数料負担がゼロ**です（支援者がご協力費12％＋税を負担）。
経費に決済手数料を挙げたままだと、開催後の実額公開で**0円**として並びます。
上記の差し替え案では、**「会場費・出演料・機材費」の3費目**に改めてあります。
