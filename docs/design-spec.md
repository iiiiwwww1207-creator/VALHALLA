## アプリ1: ヴァルハラ (Valhalla) — ホストマッチング

### コンセプト
**実写ベースのホストマッチングアプリ**。占い × 相性診断で「運命のホスト」を見つける体験。
臨場感重視 — シャンパンコールの仮想体験、1人1人のバーチャル体験を提供。

### マッチングの仕組み
**「運命」と「見た目」の2軸マッチング**:

#### 見た目軸 — 顔の系統
- **調味料顔分類**（最もポピュラー）: 酢顔 → 塩顔 → 醤油顔 → マヨネーズ顔 → 砂糖顔 → ケチャップ顔 → ソース顔（濃さスケール）
- **ざっくり分類**: 韓国系 / ジャニーズ系 / イカツい / 犬系 / 猫系
- **K-POPグループ的**: BTS系 / Gドラゴン系 / トップ系

#### 中身軸 — 接客スタイル・性格
キャストアンケートv2（全27問・9セクション）から取得したデータを元にマッチング:
- **接客タイプ**: calm / energetic / mature / passionate / healing / intellectual / sweet_talker / big_brother
- **会話スタイル**: listener / balanced / talker + ペース(calm/adaptive/energetic)
- **距離感**: friend / elder_brother / special / equal / adaptive
- **性格**: ツンデレ / オラオラ / いやし / 安心 / ギラギラ / ADHD系

#### 診断の入力
- 誕生日（占い要素）
- 見た目の好み（選択式）
- 接客スタイルの好み（MBTIライクな点数式、5〜10問）
- 「こういう女子が育てたい」要素

#### スコアリング
- primary_style_tag: +35〜40
- secondary style_tags: +15〜20
- mismatch_tags: -20〜-40
- 「固定プロフィール」+「今日の気分」の2層（将来）

### デモ画面一覧
1. **マッチング診断** — 質問フロー（5〜10問、選択式 + 誕生日）
2. **結果画面** — マッチしたホスト**トップ3**を表示（実写、顔の系統タグ + 相性%）
3. **ホストプロフィール** — 実写 + 接客タイプ + 趣味・音楽 + 「仮面と素顔の隙間」演出
4. **シャンパンコール体験** — 動画再生画面（無料15秒ショート版 / 有料フル版モック）
5. **掲示板（ホスラブ健全版）** — 顔面偏差値は数字のみ、前歴（前の店の在籍情報等）表示、女の子が安心できるUI
6. **料金シミュレーター** — ホストに行くといくらかかるか分かる機能
7. **店舗予約** — 来店予約機能（シャミオ必須要望）

### プロフィール表示の設計思想
- **「3秒で刺さる3つ + 1つの謎」**構造
- 表示順序: **なぜ → どう → 何**（Simon Sinek式）
- 「仮面と素顔の隙間」が武器 — ギャップ演出を重視

### 素材（デモ用）
- 実写 → **ホスホスの宣材写真**をまず使用（差し替えたい人は後から送ってもらう）
- 動画 → **Coming Soon**表示
- ホスト数: 22人分のスロット（タロットカードと対応）
- 誕生日データ: マッチングに必要。**外部非公開**を明確に伝える（契約書にも記載あり）

## アプリ2: ユグドラ (Yggdrasil) — アイドルマッチング + 育成

### コンセプト
**2次元アバターベースのアイドルマッチング + たまごっち型育成アプリ**。
TikTok等から流れてきたライト層を客に変換するのがゴール。
「もっと見たい！」を引き出し、育成→課金への導線を作る。
将来的にはホスト100人規模を想定。**根津イベントではこちらから入ってもらう**（ポップな入口）。

### 2ステップ体験

#### Step 1: 診断 → おすすめキャラを1人選ぶ
- ヴァルハラと同様の診断フローだが、**2次元アバター**で結果表示
- 診断結果から相性の良いキャラ候補を提示
- ユーザーが**1人を選んで「推し」に設定**
- → この子を育てていく入口になる

#### Step 2: 1日1回タロット占い
- 大アルカナ22枚 = 22人のホスト
- 毎日1枚引く → その日の運勢 + ホストからの一言メッセージ
- **毎日開く理由を作る**（定着施策）
- 5日間連続で開くと特典解放（将来）

### 占いのトーン差（ヴァルハラとの違い）
- **ユグドラ（アイドル側）**: 癒やし系・ポップな占い。「僕がいるよ」の安心感
- **ヴァルハラ（ホスト側）**: コーチング系。「一緒に頑張ってみよう」のアクション促進
- 中身（占い結果）は同じ、**届け方のトークが異なる**

### 育成機能
- ユーザーがアイテムを与える → **LLMが非決定的にキャラを成長**させる
- 育て方によってAIが勝手に進行し、未来の予想がつかない
  - キャラ同士で結婚 / カップル / 課金女子と結ばれる等の分岐
- 素材は33人分の協力体制で用意（将来）

### 課金モデル
- 課金額の一定%がホストに自動で入る
- ホストは素材提供だけで収益 → **セカンドキャリア**として訴求
- メリットの伝え方: セカンドキャリア構築、将来に活かせる、会社を作れる、お金の回し方

### デモ画面一覧
1. **診断フロー** — 選択式質問 → おすすめキャラ候補表示 → 1人を選ぶ
2. **タロット占い** — 22枚のカードから1枚引く → 今日の運勢 + ホストからの癒やし系メッセージ
3. **キャラ詳細（推しページ）** — 2次元アバター + 育成ステータス + 「もっと見たい！」CTA
4. **育成画面** — たまごっち的UI、餌やり / アイテム付与 → LLMがリアクション生成
5. **ホストの部屋** — かずまの部屋 / ぼじの部屋 / うさぎの部屋（ボイス付きモック）
6. **課金モック** — 「シャン」購入UI、シャンパン（例: 3000円）→ 特別コンテンツ解放
7. **店舗予約** — 来店予約機能（シャミオ必須要望）

### ボイス機能（将来）
- 課金すると占い結果をホスト・アイドルの声で聞ける
- 「あ」から「ん」まで全音声を収録 → AI音声合成で対応可能

### AI育成の仕組み（デモ版）
```
[ユーザーアクション]
  ↓ 餌やり / アイテム / メッセージ
[LLM API呼び出し]
  ↓ キャラの現在状態 + ユーザー履歴 → プロンプト
[非決定的レスポンス]
  ↓ キャラの反応テキスト + 状態変化
[UI更新]
  ↓ アバターの表情変化 / 新しいセリフ / ステータス変動
```

- LLMは**安い高速モデル**を使用（Gemini Flash / GPT-4o-mini等）
- キャラごとにペルソナプロンプトを持つ
- 状態はブラウザのlocalStorageに保存（デモ版）

## 共通要素

### 通貨「シャン」
- 両アプリ共通の仮想通貨
- 例: 3シャンで占い、シャンパン = 3000円分のシャン
- デモ版: UIモックのみ（実決済なし）

### 22人のタロット対応
- 大アルカナ22枚 = 22人のホスト
- 各カードにホストが紐づく
- ヴァルハラ = 実写、ユグドラ = 2次元

### 診断フロー（両アプリ共通ロジック）
- 質問セットは共通化可能（見た目の好み + 性格の好み + 誕生日）
- 出力の表現だけが異なる（実写 vs 2次元）
- ヴァルハラ: マッチ結果をそのまま表示
- ユグドラ: マッチ結果から1人を選んで「推し」に設定 → 育成開始

### LINE@連携（500名→アプリ登録がKPI）
- LINE@からWebアプリへの導線
- デモ版: QRコード / リンクのモック

```

           → スマホファースト、PWA対応
UI:        shadcn/ui ベース + カスタムテーマ（ホストクラブの世界観）

State:     localStorage（デモ版）
Deploy:    Vercel（無料枠）
Mono:      1リポジトリに2アプリ（/apps/valhalla, /apps/yggdra）
共通:      /packages/shared（診断ロジック、タロットデータ、型定義）
```
