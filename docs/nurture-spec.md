# 育成画面（Nurture）要件定義

## 概要
推しキャラにアイテムを与えたりメッセージを送ると、LLMが非決定的にリアクションを返し、キャラが成長していく。たまごっち × チャット。

## 技術要件
- **DB**: Vercel Postgres
- **LLM**: OpenRouter API（`openrouter/auto`）
- **認証**: 匿名UUID（cookie保存、初回アクセス時に自動生成）
- **デプロイ**: Vercel

## 画面（`/nurture`）

### 上部: キャラ表示
- 推しアバター + 名前 + 現在の気分
- ステータスバー: 育成度(Lv.) / 親密度 / 機嫌

### 中部: 会話ログ
- チャット形式（キャラ=左吹き出し、ユーザー=右）
- DBから直近20件を読み込み

### 下部: アクション
- アイテムボタン4つ: おやつ / プレゼント / 練習 / シャンパン
- 自由メッセージ入力 + 送信
- 各アイテムでステータス変化量が異なる

### レベルアップ
- 親密度100到達でレベル+1、親密度リセット
- レベルアップ演出（モーダル）

## LLM連携
- キャラごとのペルソナプロンプト（性格・趣味・価値観から生成）
- 癒やし系トーン、2-3文で短く返答
- レスポンスにステータス変化量を含める
- 直近5件の会話履歴をコンテキストに含める

## 推しページとの連携
- `/oshi` のステータス表示をDBから取得
- 「育成する」ボタン → `/nurture` へ遷移

## 環境変数
- `OPENROUTER_API_KEY`
- `POSTGRES_URL`（Vercel Postgres）
