これで実行できるようになった理由
CAMPFIRE は登録者の住所も連絡先も登録順も渡さない 当初の「先着300名に郵送」は実行手段が無かった。 電子媒体にして住所が不要になり、全員配布にして登録順が不要になり、 LINE で配ることで配る相手を自分たちで把握できるようになった。 名簿ゼロ・住所ゼロ・発送ゼロで回る —
1つのキャンペーンで資産が2つ積める お気に入り登録＝公開時に CAMPFIRE から通知が飛ぶ（初日の支援数）。 LINE友だち＝公開時にこちらからもう一度通知を打てる。デザイン代はここで元が取れる —
