## 東京大学の見せ方（2026-08-27）
- 背景に **安田講堂（`venue/yasuda2.jpg`）を全面に透かす**。暗幕を上段だけ薄くして
  建物のシルエットが読めるようにした（A4は時計塔まで出る）
- タイトル下の見出しを **「昼 東京大学 安田講堂 ／ 夜 CÉ LA VI 渋谷」** に変更
  （旧「CÉ LA VI SHIBUYA 2026」）。東大を先頭に置いて昼→夜の流れを1行で見せる
- ⚠️ **「東京大学とコラボ」という表現は使わない。**
  実態は ①昼の本編の会場が東大 安田講堂 ②イベント収益の寄付先が東京大学 であって、
  東大が共催・後援している事実は確認できていない。大学名の使用は無断だと止められる
  リスクがあるため、事実（会場・寄付先）のまま押し出す方針とする。
  共催/後援/協力の許諾が取れたら、その時点で正式名称と表記ルールを確認して差し替える。

## 安田講堂の画像（2026-08-27）
- kazuma 提供の**内観（大講堂）写真**と、既存の**外観**を Codex CLI で高画質化した
  （メモリのルール通り画像処理は Codex 経由。`assets/charity/venue/upscale.py` が生成スクリプト）
  - `venue/yasuda_hall_hq.jpg`     … 内観 2400×1602（元 1565×1045 を2倍→縮小）
  - `venue/yasuda_exterior_hq.jpg` … 外観 2199×2933（元 1050×1400 を3倍→縮小）
  - 処理は LANCZOS 拡大＋控えめなアンシャープ＋平坦部のノイズ低減＋コントラスト1.05。
    生成・加筆はしていない（既存ピクセルの補間のみ）
- 使い分け
  - **外観** = A4とSNS1枚目の背景（建物のシルエットで東大と分かる）
  - **内観** = SNS2枚目の背景（客席が「席の説明」と呼応する）＋A4の左の枠付き写真
- 🔴 **要確認：内観写真（元 `S__36937891.jpg`）の出所と使用許諾。**
  誰が撮影したものか未確認。フライヤー下部の画像クレジットは現在
  「安田講堂 © Kakidai（CC BY-SA 4.0）via Wikimedia Commons」のままで、
  内観・外観それぞれの実際の出所と一致しているか検証できていない。
  配布前に確定させること（CC BY-SA なら帰属表示が必須、継承条項もある）。
