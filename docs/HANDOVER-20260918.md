## 9. CAMPFIRE を自動で編集するときのコツ（ハマりどころ全部）

```
・リターン本文は 1000文字以内。超えると「システムエラー」とだけ出る
・削除ボタンは native confirm() を出す → CDPが固まる
  対策：先に window.confirm = () => true を実行してから click()
・画像は1枚ずつしか受け付けない。複数渡しても最初の1枚だけ
・画像アップの手順（これ以外だと入力が出てこない）
   ① 本文のテキスト段落を実際にマウスでクリック（JSのfocusでは不可）
   ② ツールバーの「画像の挿入」を実際にマウスでクリック
   ③ その状態で file_upload
・アップロードが「Parsing response failed」で落ちることがある
  → progressive JPEG が原因。PILで progressive=False, optimize=False に再保存すると通る
・アップした画像はカーソル位置に入る。狙った場所には入らないので、
  あとから JS で img ノードを移動させる
・本文の保存は、ページ下部の「保存する」ボタン
・編集画面は Froala。.fr-element が本文の contenteditable
・ページが巨大で find ツールが200kトークン超で落ちる → JS で直接触る
```
