## Readdy に入れる文（ここから下をそのまま貼る）

天然石アクセサリーのブランド「虎華」の、商品紹介と購入案内の1ページサイトを作ってください。
仮のサイトなので、価格・商品名・会社情報は「00」などの仮の値で構いません。

### デザイン（最重要・この通りに）
- 雑誌の誌面のような、静かで上質な編集デザイン。派手な装飾・グラデーション・ネオン・絵文字は使わない
- 配色：濃い炭色 #141515 と、生成りのベージュ #EAE7DF、白に近い紙色 #F8F7F3 をセクションごとに交互に使う。文字は炭色 #202020、濃い背景の上では #F3F1EC。差し色は使わないか、ごく細い線だけ
- 書体：日本語の見出しは明朝体（Noto Serif JP など）、細めで字間を広く。英字の見出しと数字は Didot 系の細いセリフ体。本文は細めのゴシック体
- 各セクションの頭に「01 / Story」のような番号と小さな英字ラベル（大文字・字間広め・小さく）を置き、細い横線で区切る
- 見出しは左揃え。本文は2カラム（左に大きな見出し、右に本文）を基本にする
- 写真はモノクロ寄り・彩度を落とす。角を大きく丸めた四角の枠で切り抜く
- 余白をたっぷり取る。ボタンは細い枠線か、角丸の落ち着いた塗り。影は付けない
- スマホで見たときも崩れないこと

### ページの構成（上から順に）
1. ヘッダー：左にロゴ「虎華」、右にメニュー（想い／コレクション／ご購入／よくある質問）
2. ヒーロー（濃い炭色）：左に大きな明朝の見出し「身につける、物語。」、その下に短い説明「一つずつ表情の違う天然石を、一本ずつ手で組み上げたブレスレット。」。右に、写真を少し傾けたカードとして重ねて置く。下に「コレクションを見る」ボタン
3. 大きな文字のセクション（ベージュ）：画面幅いっぱいに細いセリフ体で大きく「TORAKA」、その上に角丸の写真を重ねる
4. 01 / Story（紙色）：見出し「石の表情を、そのまま。」。本文は、ブランドを始めた理由と、石を一つずつ選んでいること（仮の文章でよい）
5. 02 / Collection（ベージュ）：商品カード3つ。各カードに写真・商品名（仮）・使っている石の名前・サイズ・価格（税込）・「詳しく見る」
6. 03 / Craft（紙色）：素材と作り方。「天然石のため、色・模様・大きさは一点ずつ異なります」という注記を必ず入れる
7. 04 / Order（濃い炭色）：左に短い案内文、右に購入カード（商品名・価格（税込）・送料・お届けまでの目安・「購入手続きへ」ボタン）
8. ご購入の前に（紙色）：01 お支払い方法／02 配送について／03 返品・交換について の3つを番号付きで並べる
9. よくある質問（アコーディオン）：サイズの選び方、お手入れ方法、ギフト包装、返品の条件
10. クロージング（ベージュ）：大きな英字「Story.」と短い一文「あなたの毎日に、ひとつの物語を。」と写真
11. フッター：ロゴ、「特定商取引法に基づく表記」「プライバシーポリシー」「お問い合わせ」へのリンク、コピーライト

### 文言のルール（必ず守る）
- これはアクセサリーの販売です。運気・金運・恋愛・健康・願いが叶う・浄化・魔除け・開運・守護・ご利益・波動・癒やしなど、身につけることで何かが良くなる・悪いことが避けられると受け取れる表現は一切使わない
- 「持たないと〜」「今買わないと〜」のように不安をあおる表現は使わない
- 「最高品質」「No.1」「日本一」「完全」「100%」など、根拠のない最上級の表現は使わない
- 「限定」「残りわずか」「今だけ」など、数や期間を強調する表現は使わない
- 神社・お寺・宗教者の名前や、「祈祷済み」「お祓い済み」といった表現は使わない
- フッター近くに小さく「本商品はアクセサリーです。特定の効果・効能をうたうものではありません。」と入れる

## 使わない言葉（チェック用）

| 分類 | 例 | 引っかかる法律 |
|---|---|---|
| 効果の約束（運・恋愛・お金） | 開運／金運アップ／恋愛成就／願いが叶う／引き寄せ／ご利益 | 景品表示法（実際より良く見せる表示＝優良誤認） |
| 体や心への効果 | 癒やし効果／ストレス解消／よく眠れる／健康／治る／血行／デトックス | 医薬品医療機器等法（薬機法）※医薬品でない物に効能をうたう |
| 不安をあおる・霊感 | 邪気を払う／魔除け／厄除け／浄化／守護／持たないと不幸に／悪い気 | 消費者契約法（霊感などで不安をあおった契約は取り消せる）・景品表示法 |
| 根拠のない最上級 | 最高品質／No.1／日本一／完全／100%天然（根拠なし） | 景品表示法 |
| 数や期間で急がせる | 限定○本／残りわずか／今だけ／本日まで（事実でない場合） | 景品表示法（有利誤認） |
| 寺社・宗教の権威を借りる | ○○神社公認／祈祷済み／お祓い済み／霊能者監修 | 景品表示法・寺社の名前の無断使用 |

- 「天然石」「水晶」などの素材名は、**事実なら書いてよい**（仕入れ先の証明を残しておく）
- 石の「意味」（石言葉）を載せるなら「〜と言い伝えられています」と**伝承として紹介**し、効果を約束しない形にする
- 最終的な文言は、公開前に弁護士か消費者問題に詳しい専門家に一度見てもらう
