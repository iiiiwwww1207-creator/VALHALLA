# 公式LINE（@328vnfzj）の設計

フライヤーの QR から入ってくる人を受け止め、**限定名刺の案内**まで届ける。
2026-09-17 作成。

---

## 前提：通数の数え方（LINEヤフー公式より）

> **「メッセージを送った回数」×「送った友だちの数」を「通数」としてカウント**します。
> **チャットの送受信、応答メッセージ、あいさつメッセージは無料でカウントされません。**

| プラン | 月額（税別） | 無料通数 | 追加 |
|---|---|---|---|
| コミュニケーション | **¥0** | **200通** | 不可 |
| ライト | ¥5,000 | 5,000通 | 不可 |
| スタンダード | ¥15,000 | 30,000通 | ¥3/通〜 |

### ここから決まること

**一斉配信は高い。自動応答はタダ。**

友だちが 300人 いる状態で一斉配信すると、**1回で300通**。無料プランは1回も打てない。
一方、**あいさつメッセージ・キーワード応答・1対1チャットは何通でも無料**。

→ **限定名刺の案内は、一斉配信ではなく「キーワード応答」で配る。**
　 支援者が自分から取りに来る形にすれば、**通数ゼロで全員に届く。**

## 全体の作り

| 仕組み | 費用 | 役割 |
|---|---|---|
| **あいさつメッセージ** | 無料 | 友だち追加の瞬間に、何のアカウントかと次の一手を伝える |
| **リッチメニュー** | 無料 | 下部に常時表示。よく聞かれる4つをタップで解決 |
| **キーワード応答** | 無料 | 「名刺」「チケット」「会場」などに自動で返す。**限定名刺の配布はここ** |
| **一斉配信** | **有料** | 本当に全員へ届けたい時だけ。年4回に絞る |

## 3. キーワード応答（無料・ここが限定名刺の配布口）

### 🎫 限定名刺（シンプル応援・デジタル版）

**課題**：CAMPFIRE は支援者の LINE を教えてくれない。
一斉配信で配ると、支援していない友だちにも届いてしまう。

**解決**：**合言葉方式**。

1. ご支援後、CAMPFIRE の**活動報告（またはメッセージ）で合言葉を伝える**
2. 支援者が LINE でその合言葉を送る
3. **自動応答で限定名刺のデータを返す**

→ 支援者だけに届く。**通数ゼロ。名簿も住所も要らない。**

応答文（キーワード：合言葉）

```
限定名刺をお届けします。

▼ ダウンロード
【URL】

・画像データです。長押しで保存できます
・データの再配布はご遠慮ください

ご支援ありがとうございました。
10月18日、渋谷でお待ちしています。
```

### そのほかの応答

| キーワード | 返す内容 |
|---|---|
| 名刺 | 「ご支援いただいた方にお配りしています。CAMPFIRE の活動報告でお伝えしている合言葉を、このトークにお送りください」 |
| チケット | 「電子チケットは10月13日〜17日にメールでお送りします。10月17日までに届かない場合は、このトークにご連絡ください」 |
| 会場 | 「渋谷の室内フロアです。会場名は決まり次第、このアカウントとCAMPFIREでご案内します」＋フロア図 |
| 締切／いつまで | 「来場コースのお申し込みは10月12日（日）23:59まで。シンプル応援は10月31日（土）までです」 |
| リターン／コース | コース一覧＋CAMPFIRE の URL |
| 時間／当日 | 当日の流れ（17:45〜21:10） |
| ステッカー | 「お気に入り登録が300件に達したら、このアカウントで全員にお配りします」 |

## 4. 一斉配信（有料・年4回に絞る）

| いつ | 内容 | 想定通数（友だち300人） |
|---|---|---|
| 公開日 | 「公開しました」＋URL | 300 |
| 300件達成時 | 限定ステッカー配布 | 300 |
| 10月10日ごろ | 来場コース締切のリマインド | 300 |
| 10月17日 | チケットの確認・当日のご案内 | 300 |
| | **合計** | **1,200通** |

### プランの判断

**ライトプラン（月5,000円）を推奨。**

- 無料プランでは **1回も打てない**（200通上限）
- ライトなら 5,000通／月。上の4回は余裕で収まる
- **必要なのは公開月と開催月の2か月だけ**なら、**合計1万円**
- VVIP席1口（33万円）に対して、**1万円で300人に4回リーチできる**。桁が違う

※ 友だちが増えるほど1回の通数も増える。1,000人になったら1回1,000通なので、
　 その時点でスタンダードを検討する。

## 5. 決めないと動かないこと

1. **合言葉**（限定名刺の受け取りキーワード）
2. **限定名刺のデジタル版の形式**（画像／PDF／限定URL）※ 本文でも〔調整中〕のまま
3. **名刺データの置き場所**（LINEに直接添付するか、URLで渡すか）
4. **ステッカーの締切と、300件未達のときの扱い** ※ 本文でも未記載
5. **リッチメニューの画像**（2500×1686px・本文図版と同じ地で作れる）
6. **有人対応の担当と時間帯**（「順次お返事します」と書くなら、誰が返すか）
