郵送をやめて解決したこと
CAMPFIRE で住所が取れるのは「配送あり」のリターンだけで、当日渡しで登録すると あとから郵送に切り替えられないという詰みがあった。郵送を無くせば住所の収集自体が不要。 送料がかからないぶん寄付額も増える。リターンは全部「配送なし」で登録する。

逆に、決めないといけなくなったこと
① シンプル応援は来場しないコースなので、現物の名刺を渡す手段が無い。 デジタル版にする＝上位コースの現物名刺とは別物になる。何を送るか確定させる。
② 当日来られなかった人にどう渡すか。②のファンミーティングを受け皿にするのが自然だが、 そこにも来られない人の扱いを先に書いておく。

これで実行できるようになった理由
CAMPFIRE は登録者の住所も連絡先も登録順も渡さない 当初の「先着300名に郵送」は実行手段が無かった。 電子媒体にして住所が不要になり、全員配布にして登録順が不要になり、 LINE で配ることで配る相手を自分たちで把握できるようになった。 名簿ゼロ・住所ゼロ・発送ゼロで回る —
1つのキャンペーンで資産が2つ積める お気に入り登録＝公開時に CAMPFIRE から通知が飛ぶ（初日の支援数）。 LINE友だち＝公開時にこちらからもう一度通知を打てる。デザイン代はここで元が取れる —
