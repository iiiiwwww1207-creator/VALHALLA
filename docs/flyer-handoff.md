## 5. 編集のしかた

HTML/CSSで作られています。**Illustrator等のデータではありません。**

### 手っ取り早い確認
`src/flyer-teaser.html` を **ブラウザ（Chrome推奨）にドラッグ&ドロップ**すると3サイズが縦に並んで表示されます。

### 文字を直す
ファイル下部の `<section class="board ...">` の中にあります。**3サイズ分あるので3箇所とも直してください。**

```html
<div class="body">
  <div class="brand">VALHALLA</div>
  <h1>Charity Live</h1>
  <p class="tagline">ビジュアル系文化を守り、継ぐ。</p>
  ...
</div>
```

### サイズ・位置を直す
CSSの下の方に、サイズごとの数値がまとまっています。

- `.t916` = 1080×1920（ストーリー）
- `.t45`  = 1080×1350（フィード4:5）
- `.t11`  = 1080×1080（正方形）

例：ストーリー版のタイトルを大きくしたい → `.t916 h1{font-size:104px}` の数字を変える。

### 写真の位置を直す
```css
.t916 .up{background-size:100% auto; background-position:center -500px}
```
- `background-size` … 大きいほど寄る／小さいほど引く
- `background-position` の px … マイナスを大きくすると写真が上に動く

## 6. デザインの決まりごと

**LP（特設ページ）と同じ視覚言語で作っています。バラバラにしないでください。**

| 項目 | 値 |
|---|---|
| 背景 | `#050307`（ほぼ黒） |
| アクセント（斜線） | `#C1121F`（クリムゾン） |
| 文字 | `#F5EFE4`（クリーム）／白 |
| 金 | `#E8CB85`（会場名・強調語だけ） |
| 欧文書体 | **Oswald**（Google Fonts） |
| 和文書体 | **Noto Sans JP**（Google Fonts） |
| 角丸 | **使わない（全て0）** ← LPのルール |

### 構図の決まり（ティザー）
```
上段 ── VALHALLA（3人）
     ／横の斜めスラッシュ
中段 ── 文字
     ／横の斜めスラッシュ
下段 ── 左：東京大学 安田講堂 ／ 右：CÉ LA VI   ← 縦の斜めスラッシュで分割
```

守るべき点（何度も直したところです）:
1. **3人の顔（特に手前の KØU）に、黒帯や文字を絶対にかぶせない。**
   写真を引いて顔全体が帯の上に収まるようにします。
2. **奥の RAY の頭を切らない。** 上端スレスレまでが限界。
3. **下段の東大は、時計塔の先端・時計・屋根まで入れる。**
4. 上下の写真は、**端に行くほどくっきり／中央に行くほど暗く**。
5. 写真を引いて左右に隙間が出る場合は、同じ写真をぼかした面（`.upbg`）で埋めています。

## 7. 書き出しかた

Mac + Google Chrome があれば `render.sh` で書き出せます。

```bash
sh render.sh
```

`export/` に JPEG と PDF が出ます。
Chromeをヘッドレスで動かして各サイズを撮影しているだけなので、
うまく動かない場合は**ブラウザで開いてスクリーンショット**でも構いません
（その場合は表示倍率100%・各ボードの実寸で撮ってください）。
